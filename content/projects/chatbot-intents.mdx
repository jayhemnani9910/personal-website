      language: "python"

        import nltk
        from nltk.stem import PorterStemmer

        stemmer = PorterStemmer()

        def preprocess(sentence):
            """
            Tokenize and stem input sentence.
            Returns list of stemmed word tokens.
            """
            # Tokenize into words
            tokens = nltk.word_tokenize(sentence.lower())

            # Remove punctuation and stem each word
            stemmed_words = [
                stemmer.stem(word)
                for word in tokens
                if word.isalnum()
            ]

            return stemmed_words

        # Example
        # Input: "What's the weather forecast?"
        # Output: ['what', 'the', 'weather', 'forecast']

    - title: "Bag-of-words"
      language: "python"
      code: |
        def bag_of_words(tokenized_input, vocabulary):
            """
            Convert tokenized input to binary bag-of-words vector.
            vocabulary: list of all unique words from training data
            """
            bag = [0] * len(vocabulary)

            for token in tokenized_input:
                if token in vocabulary:
                    idx = vocabulary.index(token)
                    bag[idx] = 1

            return bag

        # Example
        # vocabulary = ['hello', 'weather', 'forecast', 'goodbye']
        # Input tokens: ['weather', 'forecast']
        # Output: [0, 1, 1, 0]

    - title: "The whole neural network"

        import tensorflow as tf
        from tensorflow.keras import Sequential
        from tensorflow.keras.layers import Dense, Dropout

        def build_model(input_size, num_intents):
            """
            Build feedforward neural network for intent classification.
            """
            model = Sequential([
                Dense(128, input_shape=(input_size,), activation='relu'),
                Dropout(0.5),
                Dense(64, activation='relu'),
                Dropout(0.5),
                Dense(num_intents, activation='softmax')
            ])

            model.compile(
                optimizer='adam',
                loss='categorical_crossentropy',
                metrics=['accuracy']
            )

            return model

    - title: "Predicting, and knowing when not to"
      language: "python"
      code: |
        import numpy as np

        def predict_intent(user_input, model, vocabulary, intents, threshold=0.7):
            """
            Predict intent from user input with confidence thresholding.
            """
            # Preprocess input
            tokens = preprocess(user_input)
            bow = bag_of_words(tokens, vocabulary)
            bow_array = np.array([bow])

            # Get prediction probabilities
            predictions = model.predict(bow_array)[0]
            max_prob = np.max(predictions)

            # Check confidence threshold
            if max_prob < threshold:
                return {
                    'intent': 'unknown',
                    'confidence': max_prob,
                    'response': "I'm not sure I understand. Could you rephrase?"
                }

            # Get highest probability intent
            intent_idx = np.argmax(predictions)
            predicted_intent = intents[intent_idx]

            return {
                'intent': predicted_intent['tag'],
                'confidence': float(max_prob),
                'response': np.random.choice(predicted_intent['responses'])
            }

  learnings:
    - lesson: "The bot is only as good as its example phrases"
      detail: "It does well only when the patterns cover the ways people express an intent. Paraphrasing and synonym replacement widened the coverage without manual labeling."

    - lesson: "Training and inference must preprocess identically"
      detail: "An early bug: training data was stemmed and live input wasn't, and predictions were poor. I moved preprocessing into shared functions and saved its configuration alongside the model weights."

    - lesson: "Bag-of-words has no idea about word order"
      detail: "Two sentences with the same words in a different order get the same vector, so negation easily gets lost. That was acceptable at this scope. Capturing context would need n-grams or a sequential model. I found this one testing edge cases."

    - lesson: "A threshold beats a confident wrong answer"
      detail: "Without it, the bot would confidently give wrong answers to out-of-domain questions. I picked 0.7 by testing values on the validation set."

    - lesson: "The network beat simpler classifiers, on my tests"
      detail: "I also tried SVM and Naive Bayes. The network handled sparse vectors and unseen patterns better, at the cost of more complexity. I don't have the numbers to show you."

    - lesson: "Separate pieces made experiments quick"
      detail: "With intents in JSON, preprocessing in a module and the model in its own file, I could swap models or add intents without refactoring."

The bot's whole personality sits in one JSON file: each intent has example phrases and a pool of replies, and teaching it something new means editing that file and retraining. The model only decides which intent you meant, and apart from the fallback line, every word it says back is one from the corpus. It's intent classification with nothing hidden: stemmer, vector, two hidden layers, done.
