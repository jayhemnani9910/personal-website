challenge: "A moth tracking a scent, a robot sniffing for a gas leak and a swarm sweeping an area all share one problem: rare targets, a weak signal, limited energy. In turbulent air the signal arrives in scattered patches rather than a neat slope to climb, so the obvious strategy stops being obvious. People argue about which approach is best. I wanted a small sandbox where they have to compete on the same rules."
solution:
  - "Five strategies as interchangeable behaviours over one agent model: random walk, Lévy flight (mostly short hops, with rare long jumps), gradient ascent, surge-cast, and swarm stigmergy, where a decaying pheromone trail pushes agents away from ground already covered."
  - "Two plume modes. Static is a smooth signal field. Turbulent is Gaussian puffs that spawn near targets, drift with the wind and diffuse, with sensor noise on top. Every sense and every move costs energy."
  - "A leaderboard runner that averages time to first find, time to find everything, energy and success rate over repeated trials, and can save plots."
  - "A whitepaper with ten references, proposing a single rule for when to explore and when to exploit."
  - "The simulator exists twice: Python for the command line and plots, and a JavaScript version that runs the leaderboard, charts, CSV download and a live animation in your browser with no backend."
impact:
  - "Which strategy wins in turbulence isn't settled here. The repo has the runner but no committed results, so I'm not quoting a leaderboard, and numbers move between runs anyway. Run the race yourself and see."
  - "What the whitepaper does say is qualitative: in a patchy signal local gradients can mislead, and Lévy flight's advantage isn't universal."
  - "The simulator tests the five strategies, not the theory. The whitepaper's switching rule, infotaxis, PSO, quorum and intermittent search aren't in the code. And surge-cast moves with the wind here, while the whitepaper describes it moving upwind, so its score says little about the real insect behaviour."

        def get_signal(self, pos):
            if self.cfg.plume_mode == "static":
                base = self.signal_field[x, y]
            else:
                base = 0.0
                for puff in self.puffs:                 # drifting Gaussian puffs
                    dist = np.linalg.norm(pos - puff["pos"])
                    base += self.cfg.signal_strength * \
                            math.exp(-dist ** 2 / (2 * self.cfg.puff_diffusion ** 2))
            noise = np.random.normal(0.0, self.cfg.sensing_noise)
            return max(0.0, base + noise)
      explanation: "In turbulent mode the reading at a point is the sum of Gaussian bumps from drifting puffs, plus noise. Away from the puffs there's almost nothing to read, and that's the signal a gradient follower has to cope with."

This is a small project with a big name: a whitepaper on how things find rare targets, and a simulator that makes the strategies compete. The fun part is the animation in the Digital Lab, where you pick a strategy and watch the agents hunt through a drifting plume. You can switch the plume from static to turbulent and run the same race yourself. Which strategy comes out on top in turbulence is still an open question here.
