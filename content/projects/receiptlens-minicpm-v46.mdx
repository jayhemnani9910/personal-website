challenge: "A receipt says where you shop, what you bought and how you paid. Reading one with a vision-language model normally means uploading the photo to someone's API. I wanted the image and the model both on the phone. There was also a smaller obstacle: iOS apps need Xcode, Xcode needs macOS, and my machine runs Linux."
solution:
  - "A SwiftUI app takes or picks an image, sends it with a prompt to the on-device engine, and streams back the model's reading."
  - "MiniCPM-V 4.6 (GGUF) runs through llama.cpp and its multimodal mtmd layer. The Objective-C++ bridge into Swift started from OpenBMB's official iOS demo."
  - "Three modes, receipt, document and screen, each get their own prompt. The receipt one tells the model to write \"unclear\" instead of guessing and to point out any mismatch in the math."
  - "The app downloads the two model files itself, roughly 1.6 GB in total, on first use. Scans and images stay in a local history with no backend."
  - "For builds, a GitHub Actions macOS runner produces an unsigned IPA, which gets signed and sideloaded from Ubuntu with iLoader. That's for personal testing, not the App Store."

  architecture: "SwiftUI views sit on top. A MiniCPMEngine owns an MTMDWrapper, which is Swift's handle on the native runtime. Under that, MBMtmd is an Objective-C++ layer over llama.cpp's mtmd, adapted from OpenBMB's demo. All C calls now go through one serial queue, so nothing can still be running when the context is freed. On first use a ModelStore downloads the GGUF files. Each analysis takes an image and a mode prompt, loads the model if needed, adds both to the runtime in a single user turn, and streams the output. An ImageFileStore and a scan history keep results on the device."

Xcode only runs on macOS and my machine doesn't, so the repo has a GitHub Actions workflow that builds an unsigned IPA, plus a path to sign and install it from Ubuntu. Free Apple ID sideloads need periodic refreshing, which is fine for a prototype and useless for anyone else. After the audit came a full redesign: two tabs, a hero image with mode chips, history search, and an "ask again" for re-running a scan with a different prompt.
