challenge: "Deciding which biotech experiment to run next means stitching together protein databases, papers, structures and chemistry by hand. It's slow and easy to get wrong. A tool that automates it can also be wrong much faster and sound sure of itself, which is worse."
solution:
  - "A LangGraph pipeline parses the question, then walks it through UniProt, PubMed, the PDB plus normal-mode analysis, and ChEMBL when the question is about drugs."
  - "There's no LLM in the pipeline. The 'agents' are plain Python stages, and the current version needs no model API key. Experiment suggestions come from written rules, so you can read exactly why each one appeared."
  - "ProDy's ANM models a protein as a network of springs to find its flexible regions and hinges. Mutations pulled from abstracts get mapped onto those regions."
  - "An MCP server (a standard way to hand tools to a coding agent) exposes 14 tools, so Claude Code or another client can call the pipeline and do the reasoning itself."
  - "Each source has its own adapter, and every stage catches its own failures, so a dead API becomes a labelled gap in the report instead of a dead run."

  architecture: "LangGraph drives a fixed sequence: parse, resolve proteins, literature, structure, drugs, synthesis. The parser uses regex for PDB IDs and gene symbols and a name-to-UniProt map for common proteins. Then each stage does its job: UniProt for identity, PubMed for papers and mutations, the PDB for structures, ProDy ANM for flexibility, and ChEMBL for bioactivity, skipped unless the question is about drugs. Synthesis maps mutations onto flexible and rigid regions and the suggester applies its rules. Each adapter owns its httpx access with a shared base class and a 24-hour response cache. The docs mention GNM as well, but the code only runs ANM."

  keyDecisions:
    - decision: "Separate stages in plain code over one big prompt"
      reasoning: "Each source has its own access pattern, schema and failure modes, so each gets its own stage and one can fail without taking down the run. An empty lookup stays an empty lookup, because there's no model around to fill the silence with something plausible."

There's no LLM in the current version: the stages are plain Python in a LangGraph pipeline. That's what makes the data handling testable, and 150-plus tests is a lot more comforting than a good prompt when the output is a suggestion for lab work. Point Claude Code at the MCP server if you want a model doing the reasoning on top. The structure work has a limit worth knowing too: ANM tells you where a protein flexes, and it can't tell you a mutation will work.
