Tracking is the repo's own lightweight ByteTrack-style runtime: a constant-velocity Kalman filter predicts each track, then Hungarian matching on distance assigns detections. The tuned config uses minimum confidence 0.35, distance threshold 120 px and max_age 20. Analysis builds a spatial-temporal graph, and a GraphSAGE classifier runs only if you pass trained weights. FastAPI covers batch and live paths. Real RTSP and GPU runs weren't available during the audit, and the TensorRT path needs NVIDIA tooling, so both remain untested."

  keyDecisions:
    - decision: "Stock YOLOv8n (COCO person + ball) instead of waiting on a fine-tuned model"
      reasoning: "COCO's person and sports-ball classes cover enough to build tracking, graphs and serving on real footage right away, without waiting on annotation and training."
      tradeoff: "No goalkeeper, referee or team classes, and accuracy is generic. It will happily find people in the crowd too. I swapped a project-page image for exactly that false positive."
    - decision: "A small ByteTrack-style tracker over DeepSORT"
      reasoning: "Motion prediction and distance matching keep the tracker light, with no separate appearance model to run. Tuning it for soccer cut track fragmentation by 36% on a 30-frame test clip, compared with my baseline settings."
      tradeoff: "With no appearance features, long occlusions will likely break identities. That's one short clip, my own test, and not a tracking benchmark."
    - decision: "GraphSAGE over flat positional features for tactics"
      reasoning: "Tactics are relational: who is near whom, and how that changes. A graph encodes that directly, and GraphSAGE copes with player counts that change from frame to frame."
      tradeoff: "It needs labelled tactical data to learn anything. Until then, whether it's better than flat features is untested."
    - decision: "MLflow + DVC instead of a managed MLOps platform"
      reasoning: "On a solo project, a light local stack was enough, with no platform to stand up or pay for."
      tradeoff: "More manual wiring, no hosted UI, and today DVC is only a declared stage with no remote behind it."
    - decision: "FastAPI with async endpoints and a live path"
      reasoning: "Video jobs take a while and a live stream never stops, so tasks run in the background with status and cancel routes instead of holding one long request open."
      tradeoff: "The task store lives in one process and is bounded, so it won't do durable multi-worker jobs. Live throughput on real RTSP hasn't been measured."

        class InferenceConfig:

            max_frames: int = 30

        def extract_detections(result) -> list[dict]:
            """Convert a YOLO result into serialisable detections, backend-agnostic."""
            boxes = getattr(result, "boxes", None)
            if boxes is None:
                return []
            xyxy = _tensor_to_list(getattr(boxes, "xyxy", None))
            confs = _tensor_to_list(getattr(boxes, "conf", None))
            classes = _tensor_to_list(getattr(boxes, "cls", None))
            names = getattr(result, "names", {})
            dets = []
            for i, bbox in enumerate(xyxy):
                cls_id = classes[i] if i < len(classes) else None
                dets.append({
                    "bbox": bbox,
                    "confidence": confs[i] if i < len(confs) else None,
                    "class_id": cls_id,
                    "class_name": names.get(int(cls_id)) if cls_id is not None else None,
                })
            return dets

        def build_track_graph(track_windows, window=30, distance_threshold=120.0,
                              include_temporal_edges=True, max_spatial_edges=1000):
            active = track_windows[-window:]
            # nodes = each tracked player in each frame of the window (bbox -> tensor)
            edges = []

            # temporal edges: link a track to itself across consecutive frames
            if include_temporal_edges:
                temporal = {}
                for frame in active:
                    for track in frame.items:
                        cur = node_lookup[(frame.frame_id, track.track_id)]
                        if track.track_id in temporal:
                            prev_frame, prev = temporal[track.track_id]
                            if frame.frame_id - prev_frame <= window:
                                edges += [(prev, cur), (cur, prev)]
                        temporal[track.track_id] = (frame.frame_id, cur)

            # spatial edges: link players within distance_threshold px
            for node_indices in frame_to_nodes.values():
                for a, b in combinations(node_indices, 2):
                    if dist(center(nodes[a]), center(nodes[b])) <= distance_threshold:
                        edges += [(a, b), (b, a)]

        from torch_geometric.nn import SAGEConv

        class PositionClassifier(nn.Module):
            """GraphSAGE classifier producing role logits per tracked player."""
            def __init__(self, in_channels, hidden_channels=64, num_layers=2,
                         num_classes=3, dropout=0.2):
                super().__init__()
                self.convs = nn.ModuleList([SAGEConv(in_channels, hidden_channels)])
                for _ in range(num_layers - 1):
                    self.convs.append(SAGEConv(hidden_channels, hidden_channels))
                self.dropout = nn.Dropout(dropout)
                self.classifier = nn.Linear(hidden_channels, num_classes)

            def forward(self, data):
                x, edge_index = data.x, data.edge_index
                for conv in self.convs:
                    x = self.dropout(F.relu(conv(x, edge_index)))
                return self.classifier(x)
