A Flask app serves search, health and metrics, a CLI drives everything, and APScheduler runs crawls every 2 hours. Some parts are less finished than they sound. The IPFS wrapper exists but the pipeline doesn't call it. The MerkleForest table and cross-node sync are a prototype, and that table is empty in my database. Multi-chain anchoring and zk-proofs are explicit placeholders and don't work."

  keyDecisions:
    - decision: "Build on ArchiveBox instead of writing a snapshotter"
      reasoning: "ArchiveBox already captures pages in several formats. Wrapping it kept my effort on what was missing: change detection, search and provenance."
      alternatives: "A custom snapshot engine (a big problem other people have already solved); saving raw HTML only (loses ArchiveBox's multi-format capture)."
    - decision: "Make proof tools optional, and make their absence obvious"
      reasoning: "OpenTimestamps needs a CLI or server that won't always be around, so the core archiver has to run without it. A witness is only recorded once real proof bytes are on disk, so a fallback can't pass for a proof."
      alternatives: "Require the ots CLI (no CLI, no service); drop provenance entirely (loses the point of the project)."
    - decision: "Track changes with a content hash and a hash chain per version"
      reasoning: "A SHA-256 hash per version makes change detection exact and cheap. Chaining each hash to the one before means an edit to an old record breaks the chain."
      alternatives: "Byte-level diffing only (heavier, no integrity check); storing snapshots without hashes (no quick change detection, no provenance)."

    - title: "A real Merkle tree over version hashes"

        def merkle_root(leaves: List[bytes]) -> bytes:
            nodes = [sha256(l) for l in leaves]
            while len(nodes) > 1:
                next_nodes = []
                for i in range(0, len(nodes), 2):
                    a = nodes[i]
                    b = nodes[i + 1] if i + 1 < len(nodes) else nodes[i]
                    next_nodes.append(sha256(a + b))
                nodes = next_nodes
            return nodes[0]

        def verify_proof(leaf, proof, root, index) -> bool:
            h = sha256(leaf)
            idx = index
            for sib in proof:
                if idx % 2 == 0:
                    h = sha256(h + sib)
                else:
                    h = sha256(sib + h)
                idx = idx // 2
            return h == root
      explanation: "Hashes go in as leaves, so one root commits to many versions and a short proof shows that a specific one belongs. In the crawler today, each version's root covers its own hash and the previous one."

        def _has_ots_cli() -> bool:
            return shutil.which('ots') is not None

        def stamp_hash(content_hash: str, anchor_dir: Path) -> Optional[str]:
            tf = create_temp_file_for_hash(content_hash, anchor_dir)
            if _has_ots_cli():
                res = subprocess.run(['ots', 'stamp', str(tf)],
                                     capture_output=True, text=True)
                if res.returncode == 0:
                    ots_path = tf.with_suffix('.ots')
                    if ots_path.exists():
                        return str(ots_path)
            return None   # no CLI: caller keeps the hash, anchoring is skipped
      explanation: "A content hash goes through the ots CLI and comes back as a proof. No CLI means None, and the caller records no witness."

The neat trick is the chain: each version's Merkle root covers its own hash and the previous one, so an edit to an old record breaks the chain. Because capture is ArchiveBox's job, the code here stays focused on change detection, search and proof. It runs from a CLI on a 2-hour schedule, with a Flask UI and Prometheus metrics for keeping an eye on it.
