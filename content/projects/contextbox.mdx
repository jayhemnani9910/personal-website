  keyDecisions:
    - decision: "CLI-first and local-first, not a web app"
      reasoning: "The tool belongs next to the work, in the terminal, and screenshots are personal. So captures go in a local SQLite file and embeddings run locally. The web extractors and the Q&A call are the only parts meant to touch the network."
      alternatives: "A web app or browser extension (more surface, a server to host, and personal data leaving the device)."
    - decision: "Make heavy dependencies optional behind an availability guard"
      reasoning: "Sentence-transformers and OCR are big, and not everyone needs them. Import behind try/except, set a flag, and the feature switches off instead of the CLI breaking. The idea is sound, though I didn't apply it everywhere: watchdog is a bare import and takes the whole package down."
      alternatives: "Require the full dependency set (heavy install, fails if any piece is missing); split into several packages (more to maintain)."
    - decision: "Semantic search with a fallback when the model is missing"
      reasoning: "Search shouldn't die because a model isn't installed, so the embedding manager falls back to a hash-based embedding. That keeps the code running, but a hash doesn't understand meaning, so it's a stopgap at best."
      alternatives: "Embeddings only (search dies without the model); keyword search only (misses related captures)."
