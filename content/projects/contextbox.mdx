  architecture: "The package is organized around a capture-store-retrieve loop. A capture layer (screenshots with OCR, plus extractors for web pages, Wikipedia, and YouTube) writes captures and artifacts into a SQLite database. A semantic-search layer manages sentence-transformer embeddings (all-MiniLM-L6-v2) and ranks captures by cosine similarity, with a keyword fallback if the model is unavailable. An LLM layer wraps GitHub Models for question-answering, with question classification, context building from retrieved captures, source attribution, and confidence scoring. A privacy layer encrypts sensitive data with Fernet. Almost every heavy dependency is optional and guarded by a try/except availability flag, so the tool installs small and grows features as you add the [llm], [ocr], or [youtube] extras."

  keyDecisions:
    - decision: "CLI-first and local-first, not a web app"
      reasoning: "The tool sits next to where the work happens, the terminal, and the data it captures (screenshots, notes) is personal. Keeping captures in a local SQLite store and running the embedding model locally means nothing leaves the machine except the optional LLM call for Q&A."
      alternatives: "A web app or browser extension (more surface, a server to host, and captured personal data leaving the device)."
    - decision: "Make every heavy dependency optional behind an availability guard"
      reasoning: "Sentence-transformers, OCR, and YouTube extraction are large and not everyone needs all of them. Importing each behind a try/except flag and exposing pip extras ([llm], [ocr], [youtube]) keeps a base install small and lets a missing dependency disable just that feature instead of breaking the CLI."
      alternatives: "Require the full dependency set (heavy install, fails if any piece is missing); split into several packages (more to maintain and coordinate)."
    - decision: "Semantic search with a keyword fallback"
      reasoning: "Embedding-based search is the point, but it should not be a hard requirement. Cosine similarity over all-MiniLM-L6-v2 embeddings gives meaning-based retrieval, and a keyword fallback keeps search working when the model is not installed."
      alternatives: "Embeddings only (search dies without the model); keyword search only (misses semantically related captures)."

ContextBox is a CLI-first personal knowledge assistant in Python. It captures screenshots (with Tesseract OCR) and web, Wikipedia, and YouTube content into a local SQLite store, embeds everything with sentence-transformers (all-MiniLM-L6-v2) for semantic search, and answers questions over your captures via GitHub Models with question classification, source attribution, and confidence levels. It is a 27-module package with a Click + Rich CLI, optional feature groups so heavy dependencies stay optional, a Fernet-based privacy mode, and a React documentation site on GitHub Pages.
