## 🚀 How to Add a New Problem

Simply tell the AI agent:
> *"I want to solve LeetCode <Problem Number>: <Problem Name> (Difficulty: <Easy/Medium/Hard>)"*

The agent will automatically:
1. Create the directory under `easy/`, `medium/`, or `hard/`.
2. Scaffold `solution.py` containing **Brute Force**, **Optimized**, and **Most Optimal** approaches.
3. Write a comprehensive `README.md` with:
   - Complexity comparison table
   - Step-by-step walkthrough of the optimal code
   - Pointer and state-transition trace diagrams
4. Prompt you to test and update this master log!
